# 専門2-2 建築史：二題対応学習フレームワーク v0.1

## 0. 目的と射程

本フレームワークは、専門2-2で建築史の二題を選択することを前提に、既存の過去問・建築カード・様式カード・構法史資料を、論述に再利用できる形へ統合するための設計図である。

ここで予測するのは建築名ではなく、次の三点である。

1. **命題対象**：建築、類型、都市、人物、制度、技術、史料。
2. **要求操作**：同定、図示、説明、比較、背景説明、評価。
3. **必要な因果関係**：何が原因で、何が変化し、どのような建築的結果を生んだか。

建築技術史は未完成の独立領域として扱う。現在ある構造・構法の説明を、そのまま技術史の完成版とは見なさない。

## 1. 二題を別系統として準備する

### 系統A：建築・図面分析題

主な要求は、建築の同定、スケッチ、構造・構法、空間・平面、歴史・文化・社会的背景の説明である。2024〜2026年の問題3が最も安定した形式を示す。

基本因果鎖：

`材料・構法 → 荷重伝達／施工 → 平面・断面 → 空間体験 → 歴史的意味`

### 系統B：主題論述題

対象は、様式・運動、文化伝播、都市改造、人物、保存制度、建築生産、研究史などである。一つの構造テンプレートでは処理できないため、後述する六つの論述型を使い分ける。

基本因果鎖：

`歴史的条件 → 課題／目的 → 建築的手段 → 結果 → 意義・限界`

## 2. 全過去問を覆う六つの論述型

| ID | 論述型 | 中心問題 | 主な答案の順序 |
|---|---|---|---|
| A | 単体建築・図面分析 | この建築は、何をどのように実現したか | 同定 → 構造・構法 → 空間・平面 → 背景 → 意義 |
| B | 類型・構築・技術の変遷 | 何が、なぜ、どのように変化したか | 旧条件 → 限界 → 技術／需要の変化 → 新形式 → 影響 |
| C | 文化伝播・様式・運動 | 外来要素や思想がどう定着したか | 発生背景 → 原理 → 伝播／反応 → 建築化 → 影響・限界 |
| D | 都市・人物・権力 | 誰が、何のために空間を変えたか | 主体・事件 → 目的 → 空間手段 → 社会的結果 → 評価 |
| E | 保存・制度・価値判断 | 何を価値とし、どう継承するか | 脅威 → 価値 → 制度／技法 → 真正性判断 → 社会的効果 |
| F | 建築技術史・生産史・研究史 | 建築を可能にした知識と生産はどう変わったか | 資料／道具／材料 → 工程・組織 → 構法変化 → 建築的結果 → 歴史認識 |

六型は排他的ではない。一題に複数型が含まれる場合、設問の動詞ごとに段落を分ける。例えば2020年ノートル＝ダム問題は、様式と単体の説明にA、修復判断にEを用いる。

### マトリクスから言えること

- A型は近年の一題を安定して支えるが、24題全体を単独では覆わない。
- C・D・Eは、構造知識だけでは得点できない主題論述を支える。
- F型の出題数は多くないが、一度出ると専門的で代替が利かない。現状の最大の資料不足領域である。
- 予測は「今年は万神殿の次に何が出るか」ではなく、「A〜Fのどの操作を、どの対象に適用させるか」で行う。

## 4. 学習単位の共通データ構造

既存資料を文章のまま貼り付けず、次のフィールドへ分解する。空欄は欠落として可視化し、推測で埋めない。

### 4.1 全対象共通

| フィールド | 内容 |
|---|---|
| `identity` | 名称、別名、場所、年代、人物、類型 |
| `one_line_position` | 建築史上の位置を一文で示す |
| `historical_conditions` | 宗教、政治、社会、経済、気候、技術上の条件 |
| `problem_or_purpose` | 解決対象、施主の目的、旧形式の限界 |
| `mechanisms` | 具体的な構造、構法、制度、都市手法、伝播経路 |
| `results` | 空間、形態、社会、制度上の結果 |
| `significance` | 継承、転換、影響、限界、保存価値 |
| `comparison` | 比較対象と、共通の比較軸 |
| `exam_evidence` | 年度、問題、問われた操作、原文ファイル |
| `source_evidence` | 出典、該当箇所、確度、要確認事項 |

### 4.2 単体建築専用

| フィールド | 内容 |
|---|---|
| `structure_and_load_path` | 屋根・床から地盤までの荷重経路 |
| `construction_and_assembly` | 材料加工、接合、施工順序、現場／工場生産 |
| `plan_section_space` | 平面、断面、動線、光、内外関係 |
| `concept_to_parts` | 設計概念と、それを実現する具体的部位の対応 |
| `sketch_primitives` | 30秒で描く幾何、線、矢印、ラベル |
| `answer_3_lines` | 構造・空間・背景それぞれ三行版 |
| `answer_5_lines` | 概念説明・短論述版 |
| `answer_200_300ji` | 長論述版。短答の単純連結ではなく因果を追加する |
| `original_terms` | 片仮名語、日本語訳、原語、答案で採用する表記 |

### 4.3 建築技術史専用

| フィールド | 内容 |
|---|---|
| `material_supply` | 材料の産地、調達、規格、品質 |
| `tools_and_processing` | 道具、加工法、精度、歩留まり |
| `production_organization` | 工匠、職能、労働、工場／現場、標準化 |
| `construction_sequence` | 加工・運搬・建方・接合・仕上げの順序 |

## 5. 既存資料の埋め込み先

| 既存資料 | 主な利用先 | 注意 |
|---|---|---|
| `data/processed_questions/` | `exam_evidence`、設問動詞、字数、図示条件 | OCR欠落・公開画像のマスクを確認する |
| `data/建築史_知識地図.md` | 時代・地域・主要対象の索引 | 頻出一覧をそのまま答案としない |
| `src/lib/history-learning-cards.ts` ほか | 背景、特徴、関係、代表建築 | カード単位から論拠単位へ分解する |
| `src/lib/history-construction-data.ts` | 構造原理、荷重経路、空間結果 | 現在は五モジュール。技術史の生産・道具・証拠層は薄い |
| `src/lib/timeline-data.ts` | 前後関係、同時代比較 | 年代列挙ではなく転換要因を追加する |
| `data/past-exam-curation-index.*` | 過去問と知識項目の対応 | 専門1と専門2-2を混同しない |
| `data/専門2-2_建築史_答案テンプレート.md` | 日本語答案の出力形式 | 対象型に応じてテンプレートを選ぶ |

### 埋め込みルール

1. 一つの文には原則一つの主張を置く。
2. `特徴`は、可能な限り`原因`または`結果`と対にする。
3. 建築名・年代・人物には出典と確度を付ける。
4. 構造上正しい説明でも、歴史的にその時代・地域で確認できなければ技術史欄へ採用しない。
5. 同じ論拠を短答・長答・比較答案から参照し、文章の重複保存を避ける。

## 6. 三つの縦断サンプルで検証する

大量投入の前に、性質の異なる三例を完全に埋める。

| サンプル | 検証する領域 | 現時点で特に確認すべき技術史 |
|---|---|---|
| ハギア・ソフィア | 西洋古代末〜ビザンティン、ドーム、帝国・典礼 | 材料と施工、主ドーム・半ドーム・扶壁の改修史、当初構造と後世補強の区別 |
| 浄土寺浄土堂 | 日本中世木構、大仏様、宗教空間 | 貫・挿肘木等の具体的架構、宋代技術との関係、工匠・材木・施工を裏づける史料 |
| 中銀カプセルタワー | 戦後日本、工業化、新陳代謝、保存 | コアとカプセルの製作・接合・設備更新、交換構想が実現しなかった生産・管理条件 |

合格条件：各例について、図示要点、三行×三観点、五行概念説明、比較答案、技術史上の未確認事項が分離して保存されていること。

### v0.1時点の既存資料適合結果

| フィールド | ハギア・ソフィア | 浄土寺浄土堂 | 中銀カプセルタワー | 判定 |
|---|---|---|---|---|
| 名称・年代・場所・人物 | 既存 | 既存 | 既存 | そのまま移行可能 |
| 過去問出題証拠 | 複数あり | あり | あり | `past-exam-card-evidence` 等から移行可能 |
| 様式・運動・一行概要 | 既存 | 既存 | 既存 | 学習カードから分解可能 |
| 構造原理・空間結果 | 概説あり | 概説あり | 概説あり | 正確性を再確認して短答化する |
| 図像・視覚手掛かり | 画像資産あり | 画像資産あり | 画像資産あり | 平面・断面・写真の役割分けが必要 |
| 材料供給・工具・加工 | 不足 | 不足 | 一部のみ | 新規収集が必要 |
| 生産組織・施工順序 | 不足 | 不足 | 不足 | 新規収集が必要 |
| 技術史を裏づける史料 | 不足 | 不足 | 不足 | 出典付きで新規収集が必要 |
| 三行・五行・長論述の分離 | 一部あり | 未整備 | 未整備 | 同一論拠から答案長を生成する |

この試行から、既存資料は「何であるか」「代表的特徴は何か」には強い一方、「どのように作られたか」「その知識を何から確認できるか」が弱いと分かる。したがって、建築技術史資料の収集は後者を優先し、既存の様式説明を重複して増やさない。

## 7. 建築技術史の初期欠落リスト

これは最終目次ではなく、過去問から逆算した収集優先度である。

### 優先度A：過去問に直接必要

1. 日本の板材生産史：割裂、製材道具、鋸の普及、寸法・表面・供給への影響。
2. 垂木と枝割・六枝掛：尺度体系、設計・施工の標準化、成立と展開。
3. 組物の類型史：構造的役割、意匠化、軒構成、時代差。
4. ローマン・コンクリート：材料、型枠、壁・ヴォールト・ドームへの使用、組積表層との関係。
5. 鉄＋石、鉄＋煉瓦の混構造：防火、被覆、骨組、19世紀建築生産との関係。
6. 考古学・解体修理・痕跡調査が建築史研究を修正した具体例。

### 優先度B：近年の単体分析を強化

1. 古代・中世のアーチ、ヴォールト、ドームの施工と水平推力処理。
2. 日本古代〜中世木構の架構、接合、屋根下地、材木生産の変化。
3. 19世紀の鉄・ガラス・プレファブリケーションと博覧会・駅舎。
4. 20世紀のRC、PC、シェル、ケーブル、コア、プレキャストの生産史。

## 8. 制作順序

1. 本マトリクスで各過去問の要求操作を固定する。
2. 既存答案テンプレートをA〜F型へ補完する。
3. 三つの縦断サンプルを作り、必要フィールドを検証する。**完了**
4. 五つのケースファミリーを共通機構・個別差・図示・答案テンプレートへ展開する。**初版完了**
5. 過去問直結の六技術史テーマを、出典付き論拠・簡図・指定字数答案へ展開する。**初版完了**
6. 建築技術史を八類型×十変化機制×五設問操作へ再編する。**初版完了**
7. T5〜T8を下位類型、比較軸、変遷鎖、未知題入口へ展開する。**初版完了**
8. T1〜T4を下位類型、比較軸、変遷鎖、未知題入口へ展開する。**初版完了**
9. 24題を考場基準で監査し、A選択可能・B条件付き・C回避に分ける。**初版完了**
10. 監査で判明した弱点を、六枚の主題判断カードへ圧縮する。**初版完了**
11. 単体建築は全件収集せず、地域・時代別の安全選択表を作る。**初版完了**
12. 最後に90秒選択判断と、時間制限付きの二題答案で検証する。**問題・採点基準作成完了／実施待ち**

## 9. v0.1の限界

- 2019年の公開画像はマスクされており、三建築の同定を確定していない。
- 建築技術史はT1〜T8の初期分類まで完了した。地域別・年代別事例は未充足だが、考場判断に必要な優先例だけを補い、網羅的収集は行わない。
