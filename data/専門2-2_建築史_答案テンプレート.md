# 専門2-2 建築史：論述答案テンプレート

> 目的：名称を知っているだけの状態から、**図・構造／構法・空間／平面・歴史的文脈**を短い日本語で論理的につなぐ。  
> 使い方：`［　］`を自分の建築・用語に置き換え、まず骨格だけを60〜90秒で書く。その後に固有名詞・年代・図を補う。  
> 注意：下の例は「書き方」の見本であり、設問の行数・選択数に合わせて圧縮する。図像だけで名称が示されない過去問には、未確認の建築名を当てはめない。

### 日英併用ルール

- 片仮名の技術語・固有名詞は、学習時に原語まで一組で確認する：`ペンデンティブ（pendentive）`。
- 答案では初出だけを`日本語（English）`とし、以後は確実に書ける一方へ統一する。
- 英語を使っても日本語文の因果関係は崩さない：`ペンデンティブ（pendentive）によってドーム荷重を四支点へ伝える。`
- 綴りに自信がない語は無理に二重表記しない。採点に必要なのは用語の装飾ではなく、その働きの説明である。

## 0. 共通ルール：答えは「名詞の列挙」で終わらせない

### 1文の基本形

`［対象］は、［背景／目的］のもとで、［構造・空間上の手法］を用い、［建築史上の意義］を示す。`

この順序にすると、特徴と背景が因果でつながる。

### 図の最小セット（30秒）

1. **平面**：入口・主軸・中心／身廊・主要空間を太線で示す。  
2. **断面**：荷重の流れ、屋根・ドーム・ヴォールト・柱を描き、矢印を付ける。  
3. **ラベル**：図の中に日本語で `身廊` `側廊` `ドーム` `控壁` のように直接書く。  

図と本文で同じ語を使う。本文だけ、図だけの情報を作らない。

## 1. 建築1棟を四面から説明する型

**過去問対応**：2018 Q4、2024 Q3、2025 Q3、2026 Q3。  
**配分**：名称・時代1行／構造2〜3行／空間2〜3行／歴史2〜3行＋図。

### 空欄テンプレート（日語）

```text
［建築名］は［場所］にある［時代］の［建築類型／様式］である。

構造・構法：［主要部材・構造］を用い、［荷重を受ける／支える仕組み］によって
［スパン・高さ・形態］を実現する。（断面図には［部位A］と［部位B］を示す。）

空間・平面：［平面形式］をとり、［中心／軸線／内外関係］によって
［光・動線・儀礼・居住］のための空間をつくる。

歴史・文化：［施主／宗教／都市・社会背景］と結び付き、
［前代からの継承／新しさ］を示す点に建築史上の意義がある。
```

### 示范：ハギア・ソフィア（2025 Q3）

```text
ハギア・ソフィアは、コンスタンティノープルに537年に完成したビザンツ帝国の大聖堂である。

構造・構法：中央の大ドーム（dome）を四つのペンデンティブ（pendentive）で方形平面へ移し、東西の半ドームと
大きな扶壁で横推力を受ける。断面では主ドーム、ペンデンティブ、半ドーム、側廊を示す。

空間・平面：バシリカ（basilica）の長軸性と集中式のドーム空間を重ねる。ドーム基部の窓からの光により、
中央の大空間を軽く見せ、皇帝と典礼の中心を強調する。

歴史・文化：ユスティニアヌス帝のキリスト教帝国を表象し、ローマの構築技術を継ぎながら、
ペンデンティブ・ドームによるビザンツ建築の空間的達成を示した。
```

### 自检

- `ドームがある`ではなく、**どう方形平面に載せ、横推力をどう処理するか**まで書いたか。  
- `ビザンツ様式`だけでなく、**帝国・典礼・光**のどれかを歴史欄に置いたか。

## 2. 様式・運動・制度の「特徴＋成立背景」型

**過去问对应**：2018 Q5、2020 Q5、2025 Q4、2026 Q4。  
**配分**：定义1行／特征2行／背景2行／影响或代表例1行。

### 空欄テンプレート（日語）

```text
［用語］とは、［時代・地域］に成立した［様式／運動／制度］である。
特徴は、［造形・構法・空間・思想］にあり、代表例として［建築／人物］が挙げられる。
この成立には、［社会・技術・政治・思想上の条件］が関係した。
その結果、［後続の様式／建築生産／保存の考え方］に［影響／転換］を与えた。
```

### 示范：アーツ・アンド・クラフツ運動（2020 Q5、2025 Q4）

```text
アーツ・アンド・クラフツ運動は、19世紀後半のイギリスで成立した工芸・建築の改革運動である。
機械的な大量生産を批判し、手仕事、素材と構法の誠実さ、芸術と生活の統一を重視した。
その背景には産業革命による労働の疎外と製品の質の低下があり、ラスキンやモリスが思想的に支えた。
装飾を単なる表皮ではなく生活環境全体に関わるものとして捉え、アール・ヌーヴォーなどへ影響した。
```

### 禁止写法

- `〜は美しい様式である。`（判断だけで根拠がない）  
- `〜が流行した。`（谁、为什么、因何种技术／社会条件，缺失）

## 3. 都市改造・都市計画の型

**過去问对应**：2014 Q13、2024 Q4、2026 Q4。  
**顺序固定**：城市 → 事件／背景 → 目的 → 手法 → 主体 → 空间结果。

### 空欄テンプレート（日語）

```text
［都市名］では、［出来事／時代背景］を契機に［人物・権力主体］が都市改造を行った。
目的は［防災・防衛・統治・流通・象徴化］であり、
［街路の拡幅／区画整理／城郭・堀／寺社移転／河川整備］という手法が採られた。
これにより［都市の軸線・中心・境界・交通］が再編され、［結果・歴史的意義］をもたらした。
```

### 示范：豊臣秀吉による京都改造（2026 Q4 の「京都の都市改造」への练习例）

```text
京都では、戦国期の混乱後、豊臣秀吉が政治的中心の整備と都市の再編を進めた。
目的は、統治の可視化、防衛、商業・交通の統制であった。
聚楽第の造営、御土居の築造、寺院の移転・集約、街路と町割の整備が行われた。
その結果、洛中・洛外の境界と都市の中心性が再編され、近世京都の骨格が形成された。
```

### 2014「日本古代都城と中国都城の比較」用の比较框

```text
共通点：［条坊制／宮城を北に置く軸線計画］を共有する。
相違点1：［項目］は日本では［日本側］、中国では［中国側］である。
理由：［地形・既存集落・統治制度・規模］が異なるためである。
相違点2、3も同じ形で、最後に「模倣ではなく地域条件への適応」と結ぶ。
```

## 4. 保存・修復・活用・制度の型

**過去问对应**：2016 Q5、2017 Q5、2020 Q4、2022 Q5、2024 Q4、2025 Q4、2026 Q4。  
**顺序固定**：对象价值 → 损伤／课题 → 方法 → 原真性判断 → 社会意义。

### 空欄テンプレート（日語）

```text
［対象］の価値は、［建築史・技術史・地域社会］の点にある。
課題は［劣化／災害／用途喪失／安全性］であり、保存では［調査・記録・補強・修理・活用］を行う。
その際、新旧を［区別する／可逆性を確保する／既存材を最大限残す］ことが重要である。
これは真正性を単に外観の復元とせず、材料・技法・場所・使用の継続として扱うためである。
```

### 示范：ノートル＝ダム大聖堂火災後の修復（2020 Q4）

```text
ノートル＝ダム大聖堂は、初期ゴシックから盛期ゴシックへの展開を示す建築遺産である。
2019年の火災後には、失われた屋根・尖塔への対応と、残存する石造躯体の安全確保が課題となった。
修復では、火災前後の記録と実測に基づき、残存材を調査・保存しながら必要な補強と再建を行うべきである。
外観だけを新しく作るのでなく、材料・技法・歴史的痕跡を検証可能な形で継承することが真正性にかなう。
```

## 5. 構築的比較の型

**過去问对应**：2014 Q11、2016 Q9。  
**比较轴固定**：材料 → 荷重传递 → 跨度／空间 → 外观表达。先定轴，再分别写 A／B，最后总结差异。

### 空欄テンプレート（日語）

```text
［A］と［B］は、様式名ではなく構築の論理で比較する。
材料：Aは［　］、Bは［　］を主に用いる。
荷重：Aは［梁・柱／アーチ・ヴォールト／フレーム］で［　］へ伝えるのに対し、Bは［　］である。
空間：この違いにより、Aは［　］、Bは［　］というスパン・内部空間を可能にする。
表現：したがってAは［　］、Bは［　］という外観・空間表現となる。
```

### 示范：古代ギリシア建築と古代ローマ建築（2016 Q9）

```text
古代ギリシア建築と古代ローマ建築は、構築の論理で比較できる。
ギリシアは石の柱と梁による架構を基本とし、柱間と水平材の秩序が外部の周柱空間をつくる。
ローマはアーチ、ヴォールト、ドームとローマン・コンクリートを用い、壁体を厚くして大きな内部空間を覆う。
したがって前者では比例と部材の明快さが、後者では連続する曲面と包摂的な内部空間が強く表れる。
```

## 6. 建築文化の融合を読む型

**過去问对应**：2019 Q5、擬洋風建築、帝冠様式。  
**必须写出「哪两种文化」与「在哪个部位融合」**，不能只写“和洋折衷”。

```text
［建築名］は［時代］の［類型名］に位置づけられる。
［文化A］と［文化B］が接触した背景は［開国・宗教交流・技術移転・国家政策］である。
融合は［屋根／ファサード／構造／平面／装飾］に見られ、具体的には［要素A］と［要素B］が組み合わされる。
このため、単なる模倣ではなく［地域的適応／近代化／権威表現］として理解できる。
```

## 7. 類型・構法・技術の歴史的変化を説明する型

**過去問対応**：2014 Q11・Q12、2016 Q9・Q11、2022 Q4。
**目的**：現在の構造原理を説明するだけでなく、何が変化を生み、建築に何をもたらしたかを書く。

```text
［初期段階］では、［材料・道具・生産条件］のため、［構法・形式A］が用いられた。
しかし、［性能・規模・儀礼・供給上の限界］があり、［技術移転／道具／生産組織／需要］の変化によって
［新しい部材・工程・構法B］が成立した。
この変化は［荷重伝達・寸法・施工・空間］を［具体的な結果］へ変え、［建築・類型］に表れた。
したがって、これは単なる形の変化ではなく、［技術史・生産史上の意義］を持つ。
```

### 技術史答案の必須確認

- 現代の力学説明を、そのまま歴史上の施工法として書いていないか。
- 材料、道具、加工、運搬、建方、接合のどこが変化したか。
- 遺構、痕跡、文献、絵画、発掘など、何を根拠に言えるか。
- 技術変化が建築の寸法・平面・断面・意匠にどう現れたか。

## 8. 人物・権力・造営を説明する型

**過去問対応**：2017 Q4、都市改造・国家事業・宗教造営に関する設問。
**注意**：人物の伝記ではなく、建築との因果関係を書く。

```text
［人物］は［時代・地位］にあり、［政治・宗教・社会上の目的］のため［造営・都市政策］を進めた。
具体的には［建築・都市・制度］において、［配置・規模・様式・技術］を用いた。
これは［権威の可視化／宗教政策／近代化／社会統制］という役割を果たし、
［後続の都市・建築文化］に［結果・影響］を与えた。
```

### 短文の圧縮順序

`人物の位置 → 一つの目的 → 一つの造営 → 一つの建築史的結果`

## 9. 研究史・考古学的証拠を論じる型

**過去問対応**：2022 Q4。
**目的**：発掘名を列挙せず、発見前後で何が変わったかを示す。

```text
従来、［対象］は［文献・現存建築］から［旧説］と理解されていた。
しかし、［遺跡・発掘・解体修理・痕跡調査］によって［具体的証拠］が確認された。
この証拠から［配置・年代・構法・復原］が［新しい理解］へ修正された。
その意義は、［研究方法上の変化］と［建築史像への影響］を示した点にある。
ただし、［証拠の限界・復原の仮説性］を区別する必要がある。
```

## 10. 考場操作：二段階で練習する

専門2-2は180分で三題を選択するため、本番の基準は一題約55〜60分である。20分は完成答案の制限時間ではなく、骨格を作る圧縮練習として用いる。

### 段階1：20分の骨格練習

| 時間 | 行動 |
|---|---|
| 0〜1分 | 設問の動詞に丸：`図示` `説明` `比較` `背景` `論じる`。必要な段落数を決める。 |
| 1〜3分 | 答える対象を選び、名称・年代・3つのキーワードだけを余白に置く。 |
| 3〜6分 | 平面／断面の骨格を描き、本文で使うラベルを図に入れる。 |
| 6〜15分 | テンプレート順に本文を書く。各段落の最初に結論語を置く。 |
| 15〜18分 | 固有名詞、年代、主語を確認。`特徴`だけで終わる文に背景または結果を足す。 |
| 18〜20分 | 図と本文の用語、選択数、行数を最終確認する。 |

### 段階2：55分の本番答案

| 時間 | 行動 |
|---|---|
| 0〜3分 | 設問動詞、選択数、行数を確認し、答える対象を決める。 |
| 3〜10分 | 名称・年代・因果語を余白に置き、図の骨格を描く。 |
| 10〜43分 | 構造、空間、背景または主題段落を分けて本文を書く。 |
| 43〜50分 | 図へラベルと荷重・動線を加え、本文と対応させる。 |
| 50〜55分 | 固有名詞、選択数、設問漏れ、因果と限界を確認する。 |

### 最终检查清单

- [ ] 建築名／都市名を最初に書いた。  
- [ ] 図には構造または空間のラベルがある。  
- [ ] 構造と空間を同じ文で混ぜず、別に説明した。  
- [ ] 背景を一つ、結果・意義を一つ書いた。  
- [ ] 保存题写到“价值＋方法＋判断标准”，都市题写到“背景＋目的＋手法＋主体”。
