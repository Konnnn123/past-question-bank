# 建筑构法：七个剩余题型的生产发布审计

范围是専門1的 `building_construction`。构造力学和専門2-2均被排除。

| 题型 | 生产交付 |
| --- | --- |
| 共通语群填空 | 2022 的 20 空、27 词、7 个多余词结构；新语境题干 |
| 用语短答 | 2014 的 20 个独立定义；明确可接受答案 |
| 局部四选一填空 | 2024 的 20 空、每空四个同域选项 |
| 图版标签语群 | 2016 屋架的 7 标签、经核对的本地源图 |
| 图像／形式匹配 | 2020 的 10 个建筑师—结构形式关系；生成器自有示意卡而非未核对的原图分配 |
| 限定作图说明 | 2015 两项；人工量规审核 |
| 对比作图说明 | 2026 八组；人工量规审核 |

发布门禁均通过：题型原型、可考知识、单题域／关系、干扰项来源、图资策略、人工审核和学科边界。运行 `node scripts/validate-building-construction-production-formats.js` 可复核。
